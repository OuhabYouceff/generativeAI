Nom du Projet :
Conception et Développement d'une Plateforme Web pour la Génération d'Images et de Vidéos avec l'IA Générative

--------------------------------------------
Description :
Cette application a été conçue avec Flask, utilisant une base de données SQLite. Elle intègre trois modèles de diffusion : 
Deux pour la génération d'images et un pour la génération de vidéos. 
L'application dispose également d'un système d'historique pour chaque utilisateur inscrit sur la plateforme.

--------------------------------------------
Guide d'utilisation:

Étape 1 : Déployez le notebook "modelDeploymentV2.ipynb" sur Google Colab :
Rendez-vous sur Google Colab et créez un compte si vous n'en avez pas encore.

Étape 2 : Installez les dépendances :
Utilisez la commande suivante :
Avant de procéder, il est recommandé de créer un environnement virtuel. Voici comment faire :

Sur macOS :
python3 -m venv venv
source venv/bin/activate

Sur Windows :
python -m venv venv
venv\Scripts\activate

Ensuite, installez les dépendances avec la commande suivante :

pip install -r requirements.txt

Étape 3 : Lancez le serveur sur le notebook :
Utilisez un GPU T4 de Google Colab pour lancer le serveur.

Étape 4 : Copiez le lien NGROK donné par le serveur.

Étape 5 : Lancez l'application :
Utilisez l'une des commandes suivantes :

python app.py
ou
python3 app.py

Étape 6 : Créez un compte sur la plateforme.

Étape 7 : Collez le lien NGROK dans le champ prévu à cet effet sur la plateforme.

Étape 8 : Profitez de la plateforme. :)
